## 🚀 Featured Projects

### [Intune Compliance Auditor](https://github.com/athuls98/Bash-Intune-Compliance-Auditor)

A Bash-based auditing tool that authenticates to Microsoft Entra ID and retrieves Intune compliance data through Microsoft Graph.
It supports multi-device auditing, compliance scoring, stale-device detection, CSV reporting, and API error handling.

**Tech:** Bash, jq, curl, Microsoft Graph, Entra ID, Intune, OAuth 2.0

### [Network Security Detection Lab](https://github.com/athuls98/Network-Security-Detection-Lab)

A segmented virtual security lab using OPNsense and Splunk to practice centralized logging, SIEM detections, alerting, and incident investigation.

- Created separate USERS, SERVERS, SECURITY, and ATTACKER network segments with OPNsense firewall policies controlling cross-network traffic.
- Forwarded Ubuntu authentication logs and OPNsense firewall logs into Splunk and built detections for suspicious SSH authentication and repeated blocked connections.
- Created scheduled alerts, a SOC dashboard, and correlated host and firewall logs during a simulated SSH incident investigation.

**Tech:** OPNsense, Splunk Enterprise, Splunk Universal Forwarder, Kali Linux, Ubuntu, Windows 11, KVM/libvirt, Syslog, SPL.
